## [1.0.0] — 2026-03-20

### 🎉 Initial Release

**Added**
- 145+ Termux tools across 8 categories
- Real-time search filtering (name, description, category, command)
- Category dropdown filter
- Copy-to-clipboard with Android fallback support
- Dark hacker UI with neon glow per category
- Glitch animation on hero title
- CRT scanline overlay
- Responsive grid layout (mobile-first)
- Staggered card entrance animations
- Toast notification on copy
- `Ctrl+K` keyboard shortcut to focus search
- `Escape` to clear search
- Blog link to hydratermux.blogspot.com
- GitHub Pages deployment workflow

**Categories included**
- Recon (18 tools)
- Exploitation (16 tools)
- Password (8 tools)
- OSINT (13 tools)
- Network (15 tools)
- System (19 tools)
- Dev (23 tools)
- Utility (33 tools)
